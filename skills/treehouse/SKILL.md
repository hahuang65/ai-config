Treehouse lifecycle behavior belongs to the Git dotfiles executable.
This skill is a thin workflow and native-transition surface; it contains no duplicate Git lifecycle implementation.

Read [references/workflow.md](references/workflow.md), then delegate the requested operation to the installed `treehouse` command.
