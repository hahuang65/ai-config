# A5

A project is A5 only when its originating repository has effective global or system Git configuration `ai.projectFamily=a5`.
Repository-local configuration cannot grant A5 status.
For A5 projects, use `a5 auth codeartifact` and `a5 auth ecr` for service authentication, and `a5 creds renew` for credential renewal.
Use `a5 docker up`, `down`, `ps`, `logs`, and `run` for development containers.
Never stage `CONTEXT.md`, `docs/adr/**`, or `docs/features/**` in an A5 repository.
Do not add those exclusions to a shared Git ignore file.
