# A5 Project Commands

This guidance applies only to an A5 project identified by the harness baseline.
Use the `a5` commands instead of the underlying commands or scripts when an A5 project task has an equivalent shortcut.

## AWS access

- `a5 auth codeartifact` authenticates with AWS CodeArtifact so local scripts can access project packages.
- `a5 auth ecr` authenticates with Amazon Elastic Container Registry (ECR) so local scripts can access project container images.
- `a5 creds renew` renews the project's existing AWS Identity and Access Management (IAM) credentials so local scripts can use AWS services.

## Local development containers

Use these shortcuts to manage only the project's local development containers:

- `a5 docker up` starts the local development containers.
- `a5 docker down` stops the local development containers.
- `a5 docker ps` shows the local development containers.
- `a5 docker logs` shows logs from the local development containers.
- `a5 docker run` runs a local development container.
