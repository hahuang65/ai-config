01

Open a local artifact safely

A complete first tracer bullet from command invocation to a visible sandboxed artifact.

AFKComplete
What to build

Deliver the review command’s open path: validate a local HTML file, establish canonical identity, start or reuse a loopback-only server, create durable session state, serve the artifact without changing its source, and open a responsive review shell with a sandboxed frame. Invalid paths, hostile hosts, and unrelated port occupants fail safely.

Blocked by
None
Stories
1, 17, 19, 20
Test surface
Review command output and HTTP behavior against an ephemeral server.

Acceptance criteria

  • A valid HTML path opens a browser session and returns structured file, URL, and session status.
  • Canonical real paths produce stable session identity across relative paths and restarts.
  • Missing, unreadable, non-HTML, and invalid paths fail with actionable errors.
  • The runtime binds to loopback, validates Host headers, and refuses to control an unrelated server.
  • The artifact is served in a sandboxed iframe with the bridge injected only into the response; its source file remains byte-identical.
  • The shell is usable at desktop and narrow widths and exposes an accessible artifact-frame title.
02

Annotate and deliver feedback

The core human-agent loop, durable from exact browser target to foreground poll.

AFKComplete
What to build

Add annotation and Explore modes, exact element targeting, selected-text range anchors, queued annotation previews, freeform messages, bounded DOM snapshots, durable ordered feedback batches, and foreground polling. Browser payloads are schema-validated and escaped; interrupted polls never consume feedback.

Blocked by
Slice 1
Stories
2, 3, 4, 5, 6, 12, 13, 14
Test surface
Poll command plus browser interaction; pure target helpers receive direct edge-case coverage.

Acceptance criteria

  • Clicking an annotatable element queues a prompt with a stable selector, tag, and nearby text.
  • Selecting text queues exact text and start/end range anchors relative to semantic elements.
  • Native controls remain interactive in Explore mode and annotation mode is keyboard-toggleable.
  • Several annotations and one freeform message are sent as one ordered feedback batch.
  • Poll waits in the foreground and returns prompts plus a bounded compact DOM snapshot.
  • Queued feedback survives reloads, server restarts, and interrupted polls until successfully delivered.
  • Malformed, cross-origin, or oversized submissions are rejected without rendering unescaped content.
03

Approve, end, and converse

A deliberate decision lifecycle with visible agent presence and replies.

AFKComplete
What to build

Complete the review lifecycle with presence state, agent replies in the browser conversation, an explicit Approve control, a distinct End review control, final-event delivery, idempotent command behavior, and intentional reopen semantics. Closing, disconnecting, or ending never manufactures approval.

Blocked by
Slice 2
Stories
7, 8, 10, 11, 15, 18
Test surface
Poll and end command behavior with browser-level decision interactions.

Acceptance criteria

  • The browser communicates waiting, listening, working, approved, and ended states accessibly.
  • An agent reply appears in the existing conversation and re-enables feedback sending.
  • Approve emits a structured approved decision and ends the session.
  • End review and agent-side end emit ended state without approval.
  • Any final feedback submitted with Approve or End is delivered exactly once before terminal state.
  • User-approved and user-ended sessions remain closed unless intentionally reopened; agent-ended sessions can resume normally.
  • Disconnect, timeout, browser close, and process shutdown never clear a pipeline gate.
04

Reload and audit the live artifact

Keep the visual current and interrupt review only for directly proven severe failures.

AFKComplete
What to build

Watch the canonical artifact, stream change notifications, reload the frame while preserving useful scroll context, and audit settled browser geometry for severe clipping, material escape, viewport reachability, or near-total occlusion. Deliver stable evidence through poll before inviting human review and suppress cosmetic or uncertain observations.

Blocked by
Slice 3
Stories
9, 16
Test surface
Browser-observable reload and layout events; pure layout classifiers receive exhaustive direct tests.

Acceptance criteria

  • Saving the artifact causes one in-place frame reload without opening another tab.
  • Reload preserves the frame’s useful vertical and horizontal review position where possible.
  • The audit waits for fonts, samples browser geometry twice, and reports only findings stable across both samples.
  • Proven severe failures return selector, kind, axis, overflow magnitude, viewport width, severity, and persistence.
  • Intentional scrolling, truncation, masks, accessibility-hidden text, decorative overlap, tiny excursions, and uncertainty stay silent.
  • The review shell masks only proven severe failures, fails open after a bounded audit timeout, and lets the user show the artifact anyway.
05

Make pipeline review artifacts HTML-native

Use the new loop end to end for specs, tasks, and architectural review.

AFKComplete
What to build

Integrate review-artifact wherever an HTML artifact requests feedback or approval. Specs and tasks become canonical semantic HTML, later phases consume them directly, task status is visible metadata, feedback cycles regenerate the same HTML for live review, structured approval clears the existing gate, and chat remains a documented fallback.

Blocked by
Slice 4
Stories
1, 10, 15, 22, 23, 24
Test surface
Repository content and pipeline contract checks plus a representative end-to-end review fixture.

Acceptance criteria

  • Spec creates only canonical semantic HTML and advances on structured browser approval or chat fallback.
  • Tasks creates only canonical semantic HTML with slice identity, status, mode, dependencies, story coverage, and criteria metadata.
  • Code and coach read the HTML artifacts directly and update visible task completion metadata.
  • Architectural review uses review-artifact for its commit-or-explore decision.
  • Visual feedback cycles regenerate the same HTML after each batch so the open artifact never intentionally lags.
  • HTML that is merely displayed without asking for feedback does not start an unnecessary review session.
  • Browser failure falls back to the existing chat gate without weakening approval semantics.

Execution rules

How to implement the slices

One behavior at a time

Write one failing behavior test through the named seam, make it pass minimally, then refactor while green.

Vertical, not layered

Each slice must remain demonstrable through the command and browser rather than leaving disconnected server or UI scaffolding.

Security at every edge

Path, HTTP, postMessage, persistence, and rendering boundaries validate and constrain input as they are introduced.
