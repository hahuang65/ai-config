Design decision

Selected: A browser selection and review flow followed by a separate operating-system confirmation.

Why: Finding selection stays beside the evidence, while an operating-system-owned prompt outside model-visible channels is the final authorization boundary for provider mutation.

Rejected alternatives: None remained after grilling. Manual editing, automatic all-Finding publication, manual copy panels, a live agent poll, and retained per-report state are outside the agreed design.

Authoritative intentSelection flow, selection-derived comments, browser review, separate operating-system confirmation, stale-scope refusal, success and error states, keyboard order, and responsive stacking.
Directional presentationExact color, spacing, type scale, sample repository, and decorative icon treatment.
