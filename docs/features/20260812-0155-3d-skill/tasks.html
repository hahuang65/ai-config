What to build

Add a thin standalone skill entry point and an original detailed workflow that gathers geometry-changing requirements, protects ambiguous existing directories, follows local project naming, defaults new work to CadQuery, preserves existing OpenSCAD, and produces the expected parameterized source and exports without silent setup or engine changes.

  • The skill is discoverable as 3d in both harnesses and has no same-named command.
  • The workflow asks first for purpose and must-fit dimensions, then asks only relevant mounting, printer, material, load, access, and appearance questions.
  • User measurements are authoritative; researched dimensions are cited and conflicts are surfaced.
  • New projects default to CadQuery, while an existing OpenSCAD project remains OpenSCAD.
  • A local naming convention controls the product directory, source basename, multipart suffixes, and standard support filenames.
  • An ambiguous existing product directory is not overwritten.
  • Missing required tooling causes an honest stop with a mise-compatible proposal and no automatic installation or silent fallback.
02

Review evidence before spending filament

Add proportionate checkpoints that distinguish valid files from physically proven parts.

Can run unattended · AFKComplete

What to build

Extend the end-to-end workflow with functional-shape and final-model approvals, optional checkpoint adjustment by risk, temporary semantic HTML review sheets, live render updates, computed model and mesh checks, explicit physical-test limits, and cleanup after approval.

  • Ordinary parts require functional-shape and final-model approval; simple and complex parts adjust checkpoints only with a stated reason.
  • Each temporary model review sheet shows useful renders, dimensions, parameters, source citations, print assumptions, computed evidence, physical risks, and retained project files.
  • The browser review workflow collects feedback and explicit approval, with an explicit chat fallback when unavailable.
  • Geometry generation, bounds, solid or mesh integrity, and measurable constraints are presented only as computed evidence.
  • Fit, strength, creep, environmental durability, slicing, and assembly are never claimed as proven by computed checks.
  • Tight interfaces receive a small test-print recommendation and load-bearing parts receive a physical prototype recommendation.
  • The final render remains in the project, while checkpoint sheets and intermediate renders are temporary unless the user asks to retain them.
